# MiLAEDiA — مجموعه خصوصی فرش دستباف ایرانی

قالب اصلی کاتالوگ فارسی و قابل تکمیل.

**خروجی:** `MiLAEDiA_Persian_Carpet_Collection_FA.pdf` — قطع A4، ۱۹ صفحه،
۲۲۳ کادر قابل تایپ، راست‌چین، قابل باز کردن و تکمیل روی موبایل و کامپیوتر.

```
جلد  ·  مجموعه خصوصی  ·  اطلاعات فروشنده  ·  MiLAEDiA 001 … 015  ·  یادداشت فروشنده
```

**همه قاب‌های عکس خالی هستند** — جای لوگو روی جلد، عکس جلد، ۱۵ صفحه فرش و سه نوار
تصویری. عکس‌های خودتان را طبق بخش ۳ اضافه کنید.

---

## ۱ · ارسال به فروشنده

اول عکس‌ها را بگذارید (بخش ۳)، سپس همان فایل PDF را بفرستید. فروشنده آن را با
Adobe Acrobat Reader (رایگان، اندروید و آیفون)، Apple Books، Google Drive یا هر
خوانندهٔ PDF جدید باز می‌کند، داخل کادرها تایپ می‌کند، ذخیره می‌کند و پس می‌فرستد.

کادرهای «قیمت فروشنده» و «ابعاد» عمداً در قالب اصلی خالی هستند.

> به فروشنده بگویید: فایل را **ذخیره (Save)** کند و همان فایل را پس بفرستد —
> نه اسکرین‌شات و نه Print to PDF. مقدارهای تایپ‌شده داخل خود فایل ذخیره می‌شوند
> و بعداً هم خوانا و قابل ویرایش می‌مانند.
>
> برای تایپ فارسی، Adobe Acrobat Reader بهترین نتیجه را می‌دهد. فونت فارسی
> (Vazirmatn) داخل خود فایل جاسازی شده و کادرها راست‌چین تنظیم شده‌اند.

## ۲ · دریافت و بایگانی

فایل برگشتی را با نام فروشنده و تاریخ ذخیره کنید، مثلاً:

```
archive/1405-06_گالری-شیرازی_تهران.pdf
```

کادر «کد مجموعه» در صفحهٔ اطلاعات فروشنده برای همین است: کد بایگانی خودتان را
آنجا بنویسید تا شمارهٔ روی کاغذ با شمارهٔ بایگانی یکی باشد.

برای بیرون کشیدن جواب‌ها بدون باز کردن فایل:

```bash
python3 -c "from pypdf import PdfReader; f=PdfReader('returned.pdf').get_fields(); \
print('\n'.join(f'{k}: {v.get(\"/V\",\"\")}' for k,v in f.items()))"
```

### گذاشتن عکس‌ها و لوگو

فایل‌ها را داخل پوشهٔ `photos/` بریزید و دوباره `python3 build_catalog.py` را اجرا کنید.
نام فایل تعیین می‌کند عکس کجا بنشیند:

```
photos/logo.png     ←  لوگوی سایت، روی جلد  (PNG با پس‌زمینه شفاف بهترین است)
photos/cover.jpg    ←  نوار عکس پایین جلد
photos/001.jpg      ←  صفحهٔ MiLAEDiA 001
photos/002.jpg      ←  صفحهٔ MiLAEDiA 002
photos/band_intro.jpg ، band_supp.jpg ، band_final.jpg  ←  سه نوار تصویری
```

نام‌گذاری سخت‌گیر نیست. برای فرش شمارهٔ ۷ همهٔ این‌ها شناخته می‌شوند:

```
007.jpg      7.jpg      ۰۰۷.jpg      007-tabriz.jpeg      7 کاشان ابریشم.png
```

پسوندهای `.jpg .jpeg .png .webp .tif .bmp .heic` پذیرفته می‌شوند. قابی که برایش
عکسی نگذاشته باشید خالی می‌ماند، پس می‌توانید فرش‌ها را چند تا چند تا اضافه کنید.

**عکس فرش هرگز بریده نمی‌شود.** عکس داخل قاب جا داده می‌شود (contain) و فضای
باقی‌مانده با رنگ خود صفحه پر می‌شود، تا هیچ گوشه‌ای از فرش حذف نشود. برای بهترین
نتیجه فرش را از بالا، کامل در کادر و با نور یکنواخت عکس بگیرید؛ نسبت قاب حدود
۱٫۵۵ به ۱ افقی است (دست‌کم ۱۲۱۰ × ۷۸۰ پیکسل).

### تغییر شماره‌ها یا تعداد صفحه‌ها

بالای فایل `build_catalog.py`، بخش CONFIG:

```python
CARPET_COUNT  = 15          # تعداد صفحه‌های فرش
NUMBER_PREFIX = "MiLAEDiA"  # پیش از هر شماره چاپ می‌شود
START_NUMBER  = 1           # ۱ -> MiLAEDiA 001 | ۴۱ -> MiLAEDiA 041
NUMBER_DIGITS = 3           # ۳ -> 001 | ۴ -> 0001
OUTPUT        = "MiLAEDiA_Persian_Carpet_Collection_FA.pdf"
```

برای فروشندهٔ بعدی فقط لازم است: پوشهٔ `photos/` تازه، یک `START_NUMBER` تازه،
یک نام `OUTPUT` تازه، و یک بار اجرا. نام کادرها از روی شماره ساخته می‌شود
(`c001_seller_price` ، `c041_raj`)، پس داده‌های دو کاتالوگ با هم قاطی نمی‌شود.

دو کلید دیگر:

```python
USE_PLACEHOLDER_IMAGERY = False   # True -> فرش‌های نمونهٔ تولیدشده به جای قاب خالی
FRAME_CAPTIONS          = False   # True -> نوشتهٔ راهنما داخل قاب‌های خالی
```
